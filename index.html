Gate B

Stream Shorts Pipeline

An automated publishing tool that streamlines managing and uploading video content across social platforms — built to move clips from stream to TikTok without the manual upload grind.

  • Built on TikTok's official Content Posting API
  • User authorization handled via TikTok Login Kit
  • Posts only after a user explicitly connects their account
